# ゲームBGMスクリプトコンポーザー（バウハウス・アーケード版）

Google Flow Musicなどの音楽生成AI向けに、ゲーム用BGMのプロンプトと曲構成タイムラインを視覚的に組み立てるWebアプリケーションです。

---

## 概要

本ツールは、「**バウハウス幾何学ピクセルアート × アイソメトリック・アーケードコントローラー**」をモチーフにした、モダンかつポップなデザインのBGMプロンプト設計ツールです。  
ペールライラックの背景、太めの境界線、赤・青・黄・緑の原色アーケードボタン風UIを備え、視覚的・直感的なチップ操作でテンポ、調性、楽器編成、効果音、盛り上がり抑制、除外指定（ネガティブプロンプト）を設定できます。

さらに、ブラウザ標準の音源合成機能（Web Audio API）により、選択したテンポや調性で8bitピコピコ音がリアルタイムに試聴できるプレビュー機能を搭載しています。

## 主な機能とデザインの特徴

### 1. バウハウス幾何学ピクセルアートのトーン＆マナー
- **カラーパレット**: 淡いラベンダー/ペールライラック背景に、バウハウスを象徴する原色（鮮やかな赤、コバルトブルー、イエロー、グリーン、オレンジ、パープル）をアーケードボタン風に配色。
- **アーケードコントローラー風パネル**: 8bit音源プレビュアーは、アーケード筐体のコントロールパネル天板をイメージしたダークスレートグレーとカラフルなLEDでデザインされています。
- **タイポグラフィ**: 幾何学的で丸みのあるレトロフューチャーな見出しフォントと、視認性の高い日本語フォントを融合。
- **CRTモニター効果**: 画面上部の「CRT」ボタンで、ブラウン管テレビ風の走査線（スキャンライン）エフェクトのON/OFFが可能です。

### 2. 簡易8bit音源プレビュー（Web Audio API）
- 外部音声ファイルを一切使わず、ブラウザ上でリアルタイムに矩形波リード、三角波ベース、ホワイトノイズドラムを合成します。
- スライダーで設定したテンポ（BPM）や選択した調性（メジャー、マイナー、和風ペンタトニック、不穏なディミニッシュ、勇壮なドリアン）に同期して試聴できます。
- 演奏中は16ステップのLEDインジケーターが光り、リズムの感覚を視覚的に把握できます。

### 3. 盛り上がり抑制（ループBGM特化）
- 音楽生成AIが後半に勝手にドラマチックな盛り上がり（クレッシェンドや急激な展開）を作ってしまうのを防ぐための指示を付加します。
- 「ゆるめに抑える」「しっかり抑える（完全フラット）」の2段階と、ダイナミクス一定、転調なし、ドラムフィル控えめなどの個別ルールを自由に設定できます。

### 4. 曲名・世界観の反映とプリセット自動連動
- **曲名入力**: 自由な曲名やテーマ（例: 「始まりの街角」「古代神殿の亡霊」など）を入力できます。
- **プロンプトへの自動反映**: 入力した曲名が、日本語プロンプトや英語プロンプト、AI向けタグ（`[Title: ...]`）に自然に組み込まれ、AIに明確な世界観・情景を指示できます。
- **プリセット自動連動**: プリセット保存時に名前が空欄の場合、入力されている曲名が自動的にプリセット名として採用されます。また、プリセットを読み込むと当時の曲名も一緒に復元されます。
- **🎲 ランダム曲名ボタン**: レトロゲーム風の曲名をワンクリックでサジェスト・入力できます。

### 5. タイムライン統合＆ネガティブプロンプト
- 曲の長さ（15秒ジングル、30秒〜120秒ループなど）に応じて、各セクション（導入・主旋律・展開・ループ地点）の秒数配分と構成案を自動計算します。
- 「プロンプト本文にタイムラインを埋め込む」にチェックを入れると、秒数付きの構造指示がそのままプロンプト文へ組み込まれます。
- ボーカル、現代EDMビート、トラップハイハット、過度な歪みなどを除外するための「ネガティブプロンプト」を独立して出力・コピーできます。

### 6. プリセット保存・JSONファイル書き出し・URL共有
- 作成した設定に名前を付けてブラウザ内（ローカルストレージ）に保存できます。
- プリセット全体をJSONファイルとしてダウンロード（書き出し）したり、別の環境からJSONファイルを読み込んで復元できます。
- 現在の設定状態を埋め込んだ「共有URL」をワンクリックで生成・コピーできます。

### 7. 複数AIサービス対応
- Google Flow Music（自然な文章形式）
- Suno / Udio（`[Genre: 8-bit]` などのタグ指示併用形式）
- シンプル文章形式

## 起動方法

### 方法1: 付属の起動スクリプトを使う（推奨・PC単体）
Linux環境のターミナルで以下のコマンドを実行します。

```bash
cd /home/eiichi/src/game_bgm_composer
./run_server.sh
```

自動的に空いているポート（通常は 8080）でローカルサーバーが起動し、既定のWebブラウザでアプリが開きます。

### 方法2: スマホから接続する場合（Wi-Fi共有・QRコード読み取り）
スマホとPCを同じWi-Fiに接続した状態で、以下のコマンドを実行します。

```bash
cd /home/eiichi/src/game_bgm_composer
./run_mobile.sh
```

ターミナル画面上に接続用のQRコードとURL（例: `http://192.168.x.x:8080`）が表示されます。スマホのカメラでQRコードをかざすだけで、スマホのブラウザでアプリが即座に開きます。

### 方法3: Python標準サーバーで起動する場合
```bash
cd /home/eiichi/src/game_bgm_composer
python3 -m http.server 8080
```
起動後、ブラウザで `http://localhost:8080` を開いてください。

### 方法4: ブラウザで直接開く場合
ビルド不要な静的ファイル構成のため、`index.html` をブラウザにドラッグ＆ドロップして直接開くことも可能です。  
（※ブラウザのセキュリティ設定によりESモジュールがブロックされる場合は、方法1または方法2をご利用ください。）

## 画面構成と使い方

1. **左ペイン（設定パネル）**
   - **プリセット**: 設定の保存・呼び出し・JSON書き出し・URL共有を行います。
   - **雰囲気**: シーンに合った気分（フィールド、戦闘、ダンジョンなど）を選びます。
   - **楽器・音色**: 主体となる8bit音色やシンセ、パーカッションを選びます。
   - **効果音**: 曲中に散りばめたいレトロ効果音と頻度を指定します。
   - **テンポ・調性**: BPMスライダーと調性を設定し、「8bit音源で試聴」ボタンでリズムとコード感を確認します。
   - **盛り上がり抑制**: ループBGMとして扱いやすくするための平坦化指示を設定します。
   - **除外指定**: 避けたい要素（歌声など）を選びます。
   - **構成・出力形式**: 曲の尺、AIサービス、タイムライン埋め込み有無を設定します。

2. **右ペイン（生成結果）**
   - **生成スクリプト**: 「English prompt（推奨）」と「日本語プロンプト（確認用）」を切り替えられます。「プロンプトをコピー」ボタンでクリップボードに取得し、音楽生成AIに貼り付けます。
   - **除外プロンプト**: ネガティブプロンプト入力欄があるサービス向けに、除外指示文をコピーできます。
   - **構成タイムライン**: 各セクションの秒数配分と演出内容がタイムライン表示されます。

## ファイル構成

```
game_bgm_composer/
├── index.html              # メイン画面HTML（バウハウス・アーケード仕様）
├── manifest.json           # PWA用マニフェストファイル
├── run_server.sh           # ローカルサーバー起動スクリプト
├── README.md               # 説明書（本ファイル）
├── css/
│   └── style.css           # バウハウス幾何学・アーケードボタンスタイル
├── js/
│   ├── app.js              # メインコントローラー（UI・イベント管理）
│   ├── data.js             # ムード、音色、効果音、調性などの定義データ
│   ├── prompt_generator.js # プロンプト・タイムライン生成エンジン
│   ├── audio_preview.js    # Web Audio APIによるリアルタイム8bit音源合成
│   └── storage.js          # ストレージ管理・JSON入出力・共有URL
└── assets/                 # アイソメトリック・コントローラーのアイコン画像
```

## 設定データの追加・カスタマイズ方法

新しい楽器やムード、効果音を追加したい場合は、[js/data.js](file:///home/eiichi/src/game_bgm_composer/js/data.js) をテキストエディタで開いて定義を追加するだけで、画面のチップやプロンプト生成ロジックに自動的に反映されます。
